Clearsky design docs

Written in Markdown next to the code. The .html files are rendered from them with npm run docs, and npm test fails when a rendered file is out of date.

  • How Clearsky works: the parts, the sources, Now / Next, Copilot, and security.
  • Where your tickets live: Jira, GitHub Issues or no tracker, and the ticket command chats use.
  • The agent behind your chats: GitHub Copilot CLI or Claude Code, and how modes, skills and the sandbox carry over.
  • Team packs: a team's shared setup, joined with one command.
  • Clearsky on Windows: through WSL2, used from the Windows browser.
  • Plugins: adding sources on their own, each in a sandbox of its own, and writing one.
  • Clearsky in a container, reachable from the phone: on hold, design only.
  • Clearsky on the work phone, over the home network: on hold, design only.
