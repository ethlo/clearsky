# Slack for Clearsky

Slack messages that @mention you, from the last two weeks (`CLEARSKY_MENTION_DAYS`): rows under Needs you, notifications when one is new, and "Reply to …" in Now / Next for the ones from the last day. It reads only, with your user token and the `search:read` scope.

Add it with `clearsky add slack` or under Settings → Plugins, then follow the link under **Slack user token** in Settings to create the Clearsky Slack app, install it, and paste its User OAuth Token (`xoxp-…`).
